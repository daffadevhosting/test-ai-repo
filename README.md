# Test Repo

Ini repo buat test AI edit.

## Quick Start

Berikut adalah langkah-langkah cepat untuk memulai:

1. Clone repositori ini ke komputer Anda.
2. Buka folder yang telah diclone.
3. Jalankan perintah `npm install` untuk menginstal dependensi.
4. Gunakan `npm start` untuk menjalankan aplikasi.
