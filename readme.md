Proyek ini dirancang untuk menguji kemampuan AI dalam melakukan edit kode secara otomatis. Tujuan utama dari proyek ini adalah untuk mengevaluasi akurasi, efisiensi, dan kualitas output AI dalam berbagai skenario pengeditan kode. Selain itu, proyek ini juga bertujuan untuk mengidentifikasi area-area yang memerlukan peningkatan dalam proses integrasi AI dengan alur kerja pengembangan perangkat lunak.
